# Glamdring
Infraestructura para microcontroladores STM32.
Desarrollo de hardware: STM32G031

El proyecto en usa una capa de abstracción del hardware (HAL) original.

Periféricos:
* MPU6050
* NRF24

Desarrollo de hardware para:
* STM32G031

El proyecto Glamdring es un éxito.

**************************************************
Dependencias:
* Compilador ARM-none-eabi. https://developer.arm.com/downloads/-/gnu-rm
* Flasher OpenOCD: https://openocd.org/pages/getting-openocd.html
* Drivers de ST. https://www.st.com/en/development-tools/stsw-link009.html
